# Геометрия LAB (7–8-сынып)

Бұл сайт құрамында:
- `index.html` — негізгі мәзір
- `pazl/index.html` — 7–8-сыныпқа арналған жаңа интерактивті пазл
- `sheberlik/index.html` — деңгейлік жұмыс парақтары (PDF)
- `detektiv/index.html` — «Геометриялық детектив» интерактивті ойыны
- `seif/index.html` — «Құпия сейф» интерактивті ойыны

## GitHub Pages-ке жүктеу
1. GitHub-та жаңа **Public** репозиторий жасаңыз, мысалы `geometriya-lab`.
2. **Add file → Upload files** батырмасын басыңыз.
3. ZIP-ті алдын ала ашып, ішіндегі `index.html`, `pazl`, `detektiv`, `seif`, `sheberlik`, `assets` және `.nojekyll` файл/қалталарын репозиторийдің түбіріне салыңыз. (GitHub веб-интерфейсінің қалталарды жүктеуі браузерге қарай әртүрлі болуы мүмкін. Ең сенімді жолы — GitHub Desktop арқылы тұтас қалтаны push жасау.)
4. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.**
5. Сайт сілтемесі: `https://ПАЙДАЛАНУШЫ_ATY.github.io/geometriya-lab/` (өз аккаунтыңызға қарай).

Жергілікті тексеру: `index.html` файлын браузермен ашыңыз. Кейбір браузерде жергілікті файлға қатысты шектеулер туындаса, қалтада `python3 -m http.server 8000` командасын орындап, `http://localhost:8000` ашыңыз.

Бұл статикалық сайт. Оқушының аты-жөні не нәтижелері мұғалім серверіне сақталмайды. Авторизация және жалпы нәтижелер кабинеті үшін бөлек backend + дерекқор қажет.
