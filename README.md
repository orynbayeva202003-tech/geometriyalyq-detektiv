# Геометриялық детектив — дербес веб-сайт

7–8 сыныпқа арналған интерактивті геометрия тапсырмасы.

- Максималды ұпай: **6 балл**
- Сабақтағы болжамды уақыт: **7 минут**
- Негізгі файл: **index.html**
- Сайт интернетсіз де жұмыс істейді; «Геометриялық шеберлік» сайтында PDF-тер қоса берілген.

## Компьютерде ашу

`index.html` файлын Chrome немесе Safari-мен ашыңыз. Архив ішіндегі қалталардың құрылымын өзгертпеңіз.

## GitHub Pages-ке шығару (әр сайтқа бөлек репозиторий)

1. GitHub-та Public репозиторий жасаңыз, мысалы `geometriyalyq-detektiv`.
2. ZIP-ті ашып, **ішіндегі барлық файлдарды** репозиторийдің түбіріне көшіріңіз. ZIP файлының өзін жүктемеңіз.
3. GitHub Desktop арқылы **Commit to main**, содан соң **Push origin** басыңыз.
4. GitHub → **Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save**.
5. Сайт URL үлгісі: `https://USERNAME.github.io/REPOSITORY-NAME/`.

Ескерту: Оқушылардың аты-жөні, ұпайлары серверге жіберілмейді. Жауаптарды бағалау парағына жазыңыз. Бірнеше құрылғыдағы нәтижені мұғалімге автоматты жинау үшін кейін серверлік жүйе қажет болады.
